Purpose

This note documents the mathematics behind the level argument added to resi_pe.lmerMod() (lme4) and resi_pe.lme() (nlme) in RESI/R/resi_pe.R. It explains: multi-level nested mixed model (e.g., subject vs. site in a 3-level design), and a cluster-robust (“sandwich”) variance estimator, discovered while

It draws on the RESI definition in Vandekar, Tao, and Blume (2020) as Jones, Kang, and Vandekar 2025, Section 2), and the longitudinal L-RESI/ CS-RESI derivation in notes/41586_2024_8260_MOESM1_ESM.pdf (Kang et al., Nature 2024, Supplementary Section 3). The two .tex files in notes/ (Manuscript_revision.tex, supplement.tex) concern the asymptotic (non-bootstrap) confidence interval derivation and are not used here.

1. The RESI and its estimators (single-level case)

Consider independent observations W={W1,…,Wn}W = \{W_1, \dots, W_n\} with parameters θ=(α,β)\theta = (\alpha, \beta), where β∈ℝm1\beta \in \mathbb{R}^{m_1} is the target parameter and β0\beta_0 a reference value (usually 0). The Wald statistic

T2=n(β̂−β0)⊤Σβ(θ̂)−1(β̂−β0)T^2 = n(\hat\beta - \beta_0)^\top \Sigma_\beta(\hat\theta)^{-1} (\hat\beta - \beta_0)

is asymptotically χm12\chi^2_{m_1} with noncentrality parameter n(β−β0)⊤Σβ−1(β−β0)n(\beta - \beta_0)^\top \Sigma_\beta^{-1} (\beta - \beta_0). The RESI is the part of that noncentrality parameter that does not depend on nn:

Sβ=(β−β0)⊤Σβ−1(β−β0),Sβ,sgn=β/Σβ(univariate β).S_\beta = \sqrt{(\beta - \beta_0)^\top \Sigma_\beta^{-1} (\beta - \beta_0)}, \qquad S_{\beta,\text{sgn}} = \beta / \sqrt{\Sigma_\beta} \ \ (\text{univariate } \beta).

Consistent estimators (used by chisq2S()/z2S()/t2S()/f2S() in the package) are, e.g.,

Ŝβ=max(0,T2−m1n),Ŝβ,sgn=Zn.\hat S_\beta = \sqrt{\max\left(0, \frac{T^2 - m_1}{n}\right)}, \qquad \hat S_{\beta,\text{sgn}} = \frac{Z}{\sqrt n}.

The RESI is “robust” because Ŝβ\hat S_\beta remains consistent when Σβ\Sigma_\beta is estimated with a heteroskedasticity/cluster-robust (“sandwich”) covariance instead of the naive model-based one. The choice of nn and the choice of variance estimator are not independent: nn must be the number of units that the variance estimator treats as independent replicates. This coupling is the source of everything below.

2. Generalizing to clustered/longitudinal data (L-RESI, CS-RESI)

For clustered data with NN independent participants, each with nin_i repeated measurements (n=∑inin = \sum_i n_i), the longitudinal RESI (L-RESI) keeps the same formula but with Σβ\Sigma_\beta the asymptotic covariance of N(β̂−β)\sqrt N (\hat\beta - \beta) that correctly accounts for the within-cluster correlation (a GEE/cluster-robust sandwich, Σβ=A−1BA−1\Sigma_\beta = A^{-1} B A^{-1} with A,BA, B defined from the estimating equations):

S=(β−β0)⊤Σβ−1(β−β0),Ŝ=max(0,T2−p1N).S = \sqrt{(\beta - \beta_0)^\top \Sigma_\beta^{-1} (\beta - \beta_0)}, \qquad \hat S = \sqrt{\max\left(0, \frac{T^2 - p_1}{N}\right)}.

The cross-sectional RESI (CS-RESI) asks a different question: “what would the standardized effect size be if this had been a cross-sectional study (one measurement per participant), using the same NN participants?” Only the variance changes – β\beta is the same marginal parameter either way – so

Scs=(β−β0)⊤Σβ,cs−1(β−β0),S_{cs} = \sqrt{(\beta - \beta_0)^\top \Sigma_{\beta,cs}^{-1} (\beta - \beta_0)},

where Σβ,cs\Sigma_{\beta,cs} is estimated by fitting an ordinary least-squares model on the same data with each row weighted by 1/ni1/n_i (down-weighting participants with more repeated measurements to emulate one draw per participant) and taking its HC0 sandwich variance. Both L-RESI and CS-RESI use the same NN (the number of participants) – only the variance estimator differs. This is implemented in RESI/R/resi_pe.R for geeglm/ gee models, and (before this change) for lmerMod/lme with NN always taken from a single, fixed grouping factor.

3. What changes with more than one clustering level

A 3+ level nested mixed model (e.g., math ~ ... + (1 | schoolid/childid)) has two candidate units of independent replication: schools (Nschool=60N_{\text{school}} = 60) and children (Nchild=1721N_{\text{child}} = 1721, nested within schools). Nothing in Sections 1-2 singles out one of these as “the” sample size – the RESI can, in principle, be defined at either level, by treating that level’s units as the independent replicates:

The notation Σβ,k\Sigma_{\beta,k} used in an earlier version of this note was too strong. There is not generally one asymptotic covariance matrix for each arbitrary level kk. The normalization and limiting covariance depend on the asymptotic regime: which numbers of independent top-level units and lower-level observations tend to infinity, and at what rates. A more accurate generic statement is

DN(β̂−β)→d𝒩(0,Cβ),D_N(\hat\beta-\beta) \;\overset{d}{\longrightarrow}\; \mathcal N(0,\,C_\beta),

where DND_N may be scalar or block-diagonal, rather than necessarily NkI\sqrt{N_k}I. The RESI normalization must use the same DND_N that governs the covariance estimator being used. The level argument is therefore a practical choice of an independent-cluster scale for the current cluster-robust implementation, not a claim that every grouping level has a valid standalone mixed-model asymptotic distribution.

CS-RESI generalizes the same way: reweight rows by 1/ni(k)1/n_i^{(k)}, where ni(k)n_i^{(k)} is the number of rows belonging to level-kk unit ii (e.g., number of occasions per school, if $k = $ school), fit the weighted OLS, and take its HC0 sandwich variance.

3.1 What the mixed-model asymptotics actually normalize

For a two-level random-intercept model, write

Yij=β0+Xi(b)⊤βb+Xij(w)⊤βw+αi+eij,i=1,…,g,j=1,…,mi,Y_{ij}=\beta_0 + X_{i}^{(b)\top}\beta_b + X_{ij}^{(w)\top}\beta_w + \alpha_i + e_{ij}, \qquad i=1,\ldots,g,\quad j=1,\ldots,m_i,

with n=∑i=1gmin=\sum_{i=1}^g m_i. Here βb\beta_b multiplies covariates constant within cluster and βw\beta_w multiplies covariates that vary within cluster. Lyu and Welsh (2022) show that, when both the number of clusters and the minimum cluster size increase, the natural normalization for the regression parameters is

Kβ1/2(β̂−β),Kβ=diag(gIpb+1,nIpw),K_\beta^{1/2}(\hat\beta-\beta), \qquad K_\beta=\operatorname{diag}\left(gI_{p_b+1},\; nI_{p_w}\right),

$$K_^{1/2}(-)

Thus, approximately,

K_{-1/2}C_K_{-1/2}.$$

Between-cluster coefficients and the intercept are therefore g−1/2g^{-1/2} They are not all normalized by the same number of observations. In the special case where cluster sizes remain bounded, n/gn/g is bounded and all components are effectively on the g−1/2g^{-1/2} scale; the separate n−1/2n^{-1/2} rate becomes relevant when cluster sizes grow.

This is the answer to the question “what is the normalizing constant for Var(β̂−β)\operatorname{Var}(\hat\beta-\beta)?”: there is no single constant in the general mixed-model problem. For a scalar between-cluster coefficient, Var(β̂b)=O(g−1)\operatorname{Var}(\hat\beta_b) = O(g^{-1}); for a scalar within-cluster coefficient, Var(β̂w)=O(n−1)\operatorname{Var}(\hat\beta_w) = O(n^{-1}) under the increasing-cluster-size regime. For a vector containing both, use the block normalization KβK_\beta, not g\sqrt{g} or n\sqrt{n} for every component.

3.2 Sandwich form for independent top-level clusters

For a general linear mixed model partitioned into independent top-level clusters (schools in the example), let XiX_i be the fixed-effect design for cluster ii, ViV_i its fitted marginal covariance, and Ωi\Omega_i the true within-cluster covariance. If the number of top-level clusters gg grows with bounded cluster sizes, the fixed-effect estimator has the usual top-level-cluster sandwich limit:

g(β̂−β)→d𝒩(0,A−1BA−1),\sqrt g(\hat\beta-\beta)\overset{d}{\longrightarrow} \mathcal N\left(0,A^{-1}BA^{-1}\right),

where

A=limg→∞1g∑i=1gXi⊤Vi−1Xi,B=limg→∞1g∑i=1gXi⊤Vi−1ΩiVi−1Xi.A=\lim_{g\to\infty}\frac1g\sum_{i=1}^g X_i^\top V_i^{-1}X_i, \qquad B=\lim_{g\to\infty}\frac1g\sum_{i=1}^g X_i^\top V_i^{-1}\Omega_iV_i^{-1}X_i.

Consequently,

Var(β̂)≈1gA−1BA−1.\operatorname{Var}(\hat\beta) \approx \frac1g A^{-1}BA^{-1}.

This is the setting in which school-level cluster-robust inference is mathematically natural. It is also the setting required by clubSandwich::vcovCR() for a nested lmerMod: the cluster supplied to the sandwich must be at least as coarse as every random-effect grouping factor.

3.3 What assumptions are needed when cluster sizes grow

The most directly relevant reference is Lyu and Welsh (2022), who study the nested-error model above under the following regime and conditions:

  • g→∞g\to\infty and mL=minimi→∞m_L=\min_i m_i\to\infty;
  • no restriction on the relative rate at which gg and mLm_L grow;
  • independent, identically distributed random effects and errors with finite 4+δ4+\delta moments for some δ>0\delta>0 (normality is not required for the asymptotic result);
  • fixed covariates, or random covariates conditioned on, with finite 2+δ2+\delta moments;
  • limiting design moments exist and are nonsingular. In their notation, the between-cluster second-moment limit and the within-cluster design limit must be positive definite;
  • regularity/identifiability conditions keep the true variance components in the interior of the parameter space.

The important point is that there is no required finite limit for n/gn/g in that increasing-cluster-size theorem. Since mL→∞m_L\to\infty, n/gn/g also diverges (at least along the lower bound), and the within- and between-cluster parameters simply have different rates. In contrast, under the classical fixed-cluster-size regime, g→∞g\to\infty while the mim_i stay bounded; then n/gn/g is bounded and the entire parameter vector is generally on the g−1/2g^{-1/2} scale, with a more complicated joint sandwich covariance.

For a three-level design with schools, children, and occasions, write gg for schools, mim_i for children in school ii, rijr_{ij} for occasions for child jj, and n=∑i∑jrijn=\sum_i\sum_j r_{ij}. A full theorem requires a specified regime, for example:

  1. Fixed lower-level sizes: g→∞g\to\infty while the distributions of mim_i and rijr_{ij} remain bounded. School-level independent-cluster asymptotics use g\sqrt g.
  2. Growing children per school: g→∞g\to\infty and minimi→∞\min_i m_i\to\infty, with occasion counts bounded or controlled. A child/occasion-varying coefficient can have a faster normalization than a school-level coefficient, but the exact rate depends on the design matrix and the covariance structure.
  3. Growing occasions per child as well: g→∞g\to\infty, minimi→∞\min_i m_i\to\infty, and minijrij→∞\min_{ij}r_{ij}\to\infty. This needs a genuinely multi-level extension of the Lyu–Welsh argument. One should expect a block normalization with one block for each level, but there is no universal rule saying that the blocks are simply g\sqrt g, ∑imi\sqrt{\sum_i m_i}, and n\sqrt n without additional design and moment assumptions.

Thus, ratios such as (∑imi)/g(\sum_i m_i)/g and n/(∑imi)n/(\sum_i m_i) matter only after the asymptotic regime is declared. They should not be forced to converge to a finite constant in every regime: under increasing cluster sizes these ratios may diverge; under bounded cluster sizes they remain bounded. What is required is that the normalized design cross-products and covariance limits exist and remain nonsingular. For a general three-level mixed model, deriving the exact block matrix CβC_\beta and its cross-level off-diagonal terms is still an open mathematical task for this project; the current level option should be interpreted as a user-selected scaling convention, with the validity restriction in Section 4, rather than as a completed three-level asymptotic theorem.

3.4 Equal within- and between-cluster coefficients: what is the RESI?

Lyu and Welsh parameterize two potentially distinct effects: βb\beta_b for covariates constant between clusters and βw\beta_w for within-cluster deviations. For a single covariate xijx_{ij}, a within/between decomposition is

xij=x‾i+(xij−x‾i),yij=⋯+βbx‾i+βw(xij−x‾i)+⋯.x_{ij}=\bar x_i+(x_{ij}-\bar x_i),\qquad y_{ij}=\cdots+\beta_b\bar x_i+\beta_w(x_{ij}-\bar x_i)+\cdots.

Here βb\beta_b compares clusters with different means of xx, whereas βw\beta_w compares units with different xx values within the same cluster. Equality of their true numeric values does not make these the same estimand: they are identified by different sources of design variation and have different asymptotic rates.

Equal true values, estimated separately

Suppose the unrestricted model is fitted and the true values happen to obey βb=βw=β\beta_b=\beta_w=\beta. Lyu–Welsh still give separate estimators:

g(β̂b−βb)→dN(0,Cb),n(β̂w−βw)→dN(0,Cw),\sqrt g(\hat\beta_b-\beta_b)\overset{d}{\longrightarrow}N(0,C_b), \qquad \sqrt n(\hat\beta_w-\beta_w)\overset{d}{\longrightarrow}N(0,C_w),

where CbC_b and CwC_w are the corresponding covariance blocks in their limiting matrix CC. Under their theorem the between and within blocks are asymptotically independent. Thus

Var(β̂b)∼Cb/g,Var(β̂w)∼Cw/n.\operatorname{Var}(\hat\beta_b)\sim C_b/g, \qquad \operatorname{Var}(\hat\beta_w)\sim C_w/n.

For scalar effects, the corresponding RESIs are

Sb=|β−β0|Cb,Sw=|β−β0|Cw.S_b=\frac{|\beta-\beta_0|}{\sqrt{C_b}},\qquad S_w=\frac{|\beta-\beta_0|}{\sqrt{C_w}}.

The signed forms preserve the sign of β−β0\beta-\beta_0. Equal coefficients do not imply equal standard errors or equal RESIs: CbC_b and CwC_w encode different design information. If the scientific target is whether the effects are equal, that is a third question. Under the theorem’s block independence result,

Var(β̂b−β̂w)∼Cb/g+Cw/n,\operatorname{Var}(\hat\beta_b-\hat\beta_w) \sim C_b/g+C_w/n,

so a Wald test of H0:βb=βwH_0:\beta_b=\beta_w is not either level-specific RESI.

Equality imposed as a model constraint

Alternatively, impose βb=βw=γ\beta_b=\beta_w=\gamma during fitting. This gives one constrained estimator, not two separate estimates that happen to be similar. Its score combines information from the between- and within-cluster design. Schematically, with asymptotically orthogonal score components and scalar information contributions Jb,Jw>0J_b,J_w>0,

Var(γ̂)≈(gJb+nJw)−1.\operatorname{Var}(\hat\gamma)\approx(gJ_b+nJ_w)^{-1}.

This is an information-order illustration, not a general Lyu–Welsh formula for a constrained fit. If n/g→∞n/g\to\infty and within-cluster information is nonzero, the within contribution may dominate and the constrained estimator may have a n\sqrt n rate; if n/gn/g remains bounded, both contributions may be of order gg and the rate may be g\sqrt g. The exact normalization depends on the constrained estimating equations, covariance model, and design. A RESI for γ\gamma must use the covariance and normalization of this constrained estimator; it is not an average of SbS_b and SwS_w.

Contrast with L-RESI and CS-RESI

L-RESI and CS-RESI distinguish two covariance targets for the same marginal regression parameter: L-RESI accounts for longitudinal dependence; CS-RESI uses the covariance for the counterfactual cross-sectional design with one measurement per participant. In contrast, βb\beta_b and βw\beta_w are different parameters tied to between- and within-cluster covariate variation. Therefore:

  • Equal true values of βb\beta_b and βw\beta_w do not make their separate RESIs equal and do not turn either into CS-RESI.
  • CS-RESI is not generally a within-cluster RESI. Its reference design samples one row per participant; a within-cluster effect is identified from deviations among units inside clusters and has its own information and asymptotic rate.
  • L-RESI is not automatically a between-cluster RESI. It uses the longitudinal covariance for its target marginal coefficient; a between-cluster coefficient’s information is driven by the number and design of independent clusters.

Takeaway: specify the scientific target first: a between-cluster effect, a within-cluster effect, a test that those effects are equal, or one constrained common slope. Then derive the covariance and normalization for that estimator. The Lyu–Welsh theorem handles the first two separately; it does not imply that equality of their true coefficients merges their RESIs.

4. A hard constraint: not every level admits a valid cluster-robust variance

While implementing this, clubSandwich::vcovCR() raised

Non-nested random effects detected. clubSandwich methods are not
available for such models.

when level was set to the child level for Model A (which also has a school random intercept). This is not a bug or an implementation detail – it reflects a real mathematical requirement of cluster-robust variance estimation, and it is the central finding of this note.

4.1 Why the constraint exists

A cluster-robust (“sandwich”) variance estimator is valid only if residual correlation is fully contained within clusters, i.e., different clusters must be genuinely independent. Consider Model A’s data-generating process

Yijt=Xijt⊤β+bi+bij+εijt,bi∼N(0,σschool2),bij∼N(0,σchild2),Y_{ijt} = X_{ijt}^\top \beta + b_i + b_{ij} + \varepsilon_{ijt}, \qquad b_i \sim N(0, \sigma^2_{\text{school}}), \ \ b_{ij} \sim N(0, \sigma^2_{\text{child}}),

for occasion tt of child jj in school ii. If we cluster at the child level (cluster == childid:schoolid), two different children j≠j′j \ne j' in the same school ii are placed in different clusters – but Cov(Yijt,Yij′t′)=σschool2≠0\mathrm{Cov}(Y_{ijt}, Y_{ij't'}) = \sigma^2_{\text{school}} \ne 0 because they share the school random effect bib_i. The sandwich estimator’s “meat” matrix implicitly assumes this cross-cluster covariance is zero, so clustering at the child level silently drops (rather than robustly estimates) the school-level correlation, and the resulting variance estimate is invalid, not merely conservative or approximate. Clustering at the school level does not have this problem: two rows in different clusters (different schools) share no random effect by construction, so they are genuinely independent, and any within-school correlation (from either bib_i or bijb_{ij}) is fully absorbed into the school cluster.

4.2 The general rule and how it is checked

In general, for a cluster variable cc to give a valid cluster-robust variance for a mixed model with random-effect grouping factors g1,…,gQg_1, \dots, g_Q, cc must be constant within every level of every gqg_q – equivalently, cc must be at least as coarse as (a refinement of) the model’s outermost random-effect grouping factor. clubSandwich checks this internally (is_nested_lmerMod()/check_nested()): for each model grouping factor gqg_q and each of its levels, the candidate cluster cc must take exactly one value. Concretely, for Model A:

  • level = "schoolid" (60 groups): valid – every child (childid:schoolid) belongs to exactly one school, and every school belongs to exactly one school (trivially). This is also clubSandwich’s own default (get_outer_group()), which always uses the model’s outermost grouping factor.
  • level = "childid:schoolid" (1721 groups): invalid – most schools contain more than one child, so a school’s rows span multiple childid:schoolid clusters, meaning the required cross-cluster independence is violated.

Practical consequence: for a KK-level nested random-intercept model, level can only be validly set to the outermost grouping factor (or, equivalently, level = NULL’s coarsest available choice) when a cluster-robust vcovfunc (the package default, clubSandwich::vcovCR) is used. RESI/R/resi_pe.R now raises an informative error (rather than clubSandwich’s cryptic one) when an explicit level is not achievable this way, pointing back to this note.

4.3 Why the default behavior mixes levels, and why that is preserved

Before this change (and still, when level = NULL), resi_pe.lmerMod()/ resi_pe.lme() used NN from the model’s finest grouping level (e.g., number of children) together with clubSandwich‘s own default variance clustering, which is the outermost level (e.g., schools) – i.e., the pre-existing default already mixed two different levels’ information (a finer NN paired with a coarser-clustered variance). Given Section 4.1-4.2, this default is not the mathematically self-consistent “SkS_k at a single level kk” of Section 3 – but it is retained unchanged here for backward compatibility (all existing numeric outputs and tests are unaffected). When level is explicitly supplied, the implementation now also re-clusters the variance at that level (raising the error in Section 4.2 if it is not a valid choice), so that an explicit level gives the mathematically consistent quantity from Section 3, while the default remains exactly what it was before.

5. Mapping to the implementation

RESI/R/resi_pe.R:

  • .resiMixedLevelInfo(ngrps_vec, level) resolves level (NULL, a grouping-factor name, or a numeric index into summary(model)$ngrps / summary(model)$dims$ngrps[seq_len(dims$Q)]) to list(N, name, explicit).
  • N is used directly as the sample size in chisq2S()/z2S() for both L-RESI and CS-RESI (Section 3).
  • The per-row grouping factor for the resolved level (model.full@flist[[name]] for lmerMod; data[[name]] for lme, since nlme’s grouping variables are literal data columns, unlike lme4’s synthetic nested-interaction labels such as "childid:schoolid") is used both:
    • as the CS-RESI reweighting variable (1/ni(k)1/n_i^{(k)}, Section 3), and
    • (only when level is explicit) injected as vcov.args$cluster for clubSandwich::vcovCR, so the L-RESI variance is clustered at the same level as NN (Section 4.3).
  • If clustering at an explicit level is mathematically invalid (Section 4.2), the clubSandwich error is caught and re-raised with a message pointing back to this note.

7. Brainstorming: a genuine student-level effect size

Section 4 shows that a cluster-robust L-RESI can only be validly computed at a level as coarse as the model’s outermost random effect (schools, in Model A) – clustering at the child level is not just “less robust,” it is mathematically invalid, because clustering assumes independence across clusters, and children in the same school are not independent (they share the school random effect). But this is often the wrong question to ask. Cluster-robust independence is a strong, somewhat blunt requirement: it demands independence for every parameter in the model simultaneously, even though a single fixed-effect parameter, like the coefficient on a child-level covariate, is not actually estimated by comparing schools to each other. It is estimated (largely) by comparing children within the same school to each other. If the applied question is “what is the effect size of adding one more student’s worth of information to a child-level covariate,” rather than “what is the effect size of adding one more school,” then treating Nschool=60N_{\text{school}} = 60 as the sample size, and requiring cluster-robust independence at the school level, is answering a different question than the one being asked. This section brainstorms ways to more directly target that question. None of these are implemented; they are recorded here as candidate directions.

7.1 Use the model-based (parametric) variance instead of a sandwich

The cluster-robust requirement in Section 4 is a property of sandwich variance estimators specifically – it is not a property of the mixed model itself. The model-based variance of β̂\hat\beta, Var(β̂)=(X⊤Σ̂Y−1X)−1\mathrm{Var}(\hat\beta) = (X^\top \hat\Sigma_Y^{-1} X)^{-1}, where Σ̂Y\hat\Sigma_Y is the fitted marginal covariance of YY implied by the random-effects structure (school variance + child variance + residual variance), already correctly propagates variance from all levels simultaneously, including the within-school (child- and occasion-level) variability that a child-level covariate’s estimate actually depends on. It does not require choosing a single “level” to cluster at, so the tension in Section 4 does not arise. The cost is that it is only as valid as the parametric model (correct random-effects distribution, correct variance structure) – it is not robust to their misspecification the way a sandwich estimator is. A “student-level RESI” could plausibly be defined using vcov(model) (or nlme’s equivalent) directly, with NN = number of children, explicitly flagged as model-based, not cluster-robust. This is close to what the pre-existing default does today when vcovfunc = stats::vcov is requested (the naive branch already implemented in resi_pe.lmerMod/resi_pe.lme) – except currently that branch still divides by whichever NN level resolves to, without a principled argument for why the model-based variance’s effective information content matches that particular NN. Making this connection precise (i.e., showing what NN the model-based variance behaves as if it were divided by, for a child-level covariate specifically) is unresolved.

7.2 Between/within decomposition of the covariate

For a covariate XX that varies at the child level, its effect is identified from two distinct sources of variation: the within-school deviations Xij−X‾i⋅X_{ij} - \bar X_{i\cdot} (differences between children in the same school) and the between-school means X‾i⋅\bar X_{i\cdot} (differences in the school-level average of XX). The classic multilevel “contextual effects” decomposition splits a single coefficient into within- and between-cluster components with their own standard errors (e.g., via centering XX at the school mean and adding the school mean as a separate covariate). If a covariate is well-approximated as purely within-cluster (its between-school component is negligible or explicitly controlled for), the within component’s sampling variability is governed by variation among children within schools, which is a NchildN_{\text{child}} -scale quantity, and does not require treating schools as independent replicates. A “student-level RESI” for such a covariate could target only the within-cluster component of β\beta, using the within-cluster contribution to Σβ\Sigma_\beta, evaluated with NchildN_{\text{child}} (or, more precisely, degrees of freedom based on children within schools, Nchild−NschoolN_{\text{child}} - N_{\text{school}}). Open issue: this only cleanly applies to covariates that are (near-)purely within-cluster; a covariate with substantial between-school variation (e.g., a covariate that is almost constant within a school but differs across schools) does not have a well-defined “student-level” effect separate from the school-level one, because the identifying variation genuinely comes from comparing schools.

7.3 Design-effect / effective-sample-size interpolation

Survey statistics has a standard notion of an effective sample size under clustering, the design effect DEFF=1+(m‾−1)ρ\mathrm{DEFF} = 1 + (\bar m - 1)\,\rho, where m‾\bar m is the average cluster size and ρ\rho is the intraclass correlation (ICC) of the outcome (or, more precisely here, of the covariate/residual relevant to β\beta). The effective sample size Neff=n/DEFFN_{\text{eff}} = n / \mathrm{DEFF} interpolates continuously between NschoolN_{\text{school}} (when ρ→1\rho \to 1, all information is at the cluster level) and nn (total rows/occasions, when ρ→0\rho \to 0, clustering carries no information). This is attractive because it does not require picking a discrete “level” at all, and it naturally produces a small effective nn for covariates that are highly confounded with school membership and a larger one for covariates that vary freely within schools – i.e., it could give an answer to “how much did adding one more child’s worth of information really help” for the specific covariate in question, rather than a single generic per-model choice of level. Open issue: this is usually derived for a single scalar summary (the outcome’s ICC) in simple cluster designs; extending it per-coefficient in a general mixed-model Wald test, and connecting it back to a valid noncentrality-parameter definition for the RESI (Section 1), is nontrivial and not attempted here.

7.4 Empirical (bootstrap) sampling variability at the desired level

The hybrid plasmode simulation developed earlier in this project (tests/test_egsingle_hybrid_plasmode.R; see instructions/instructions.md) is, in effect, a way to sidestep this whole question empirically: it draws fresh school and child random effects (from rescaled BLUPs) and fresh residuals for a fixed covariate design, and measures the actual across-replicate sampling variability of β̂\hat\beta, mc_sd. That quantity already reflects the true joint (school + child + residual) sampling variability without requiring a cluster-robust assumption at any single level, and it empirically matched the model-based (parametric) vcov(model) SEs closely (Section 3.1 vs. the corrected direct-DGP results). This suggests the model-based variance (Section 7.1) may already be an adequate stand-in for “the correct” variance under this model, without needing a bootstrap in practice – but a bootstrap could still be useful as a robustness check against random-effects misspecification, playing a role analogous to what the cluster-robust sandwich is meant to provide at a single valid level.

8. Open questions / not addressed here

  • None of Section 7 is implemented. These are candidate directions for a genuinely student-level (or, more generally, “coarser-than-desired cluster” level) effect size that does not require cluster-level independence; picking one (or a combination) and formalizing/validating it is future work.
  • Auto-detection of the “right” level. This note documents how to compute the RESI at a level the user specifies; it does not address automatically choosing or recommending a level based on the study design (the original Goal 2 design question in instructions/instructions.md).
  • Confidence intervals. This note only concerns point estimation. The asymptotic CI machinery (resi_asymptotic.R) has not been extended to the cluster-robust, multi-level setting, and the nonparametric bootstrap CI for resi.lmerMod()/resi.lme() is not yet implemented at all (resi() still warns and returns point estimates only).
  • Generalized (non-Gaussian) mixed models. Not addressed; resi_pe does not yet have a glmer method.
  • Non-nested / crossed random effects. Section 4’s constraint was derived and checked for purely nested designs (schoolid/childid); crossed random-effects models (e.g., (1|item) + (1|subject)) may have no single grouping factor coarse enough to satisfy the constraint at all, in which case no level (other than treating the whole sample as one cluster) would admit a valid cluster-robust variance.
